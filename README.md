# {mathpsychr}

Provides reusable infrastructure for generative modelling, simulation, and
model evaluation in mathematical psychology, independent of specific theories
or experimental paradigms.

---

Includes:

- **Directed acyclic graph generation** (class `mpr_dag`):  
  Draw customisable structural causal models via {ggdag}.
- **Power analysis infrastructure** (class `mpr_power`):  
  Compute Type M and Type S error estimates via the method presented in
  Gelman & Carlin([2014](https://doi.org/10.1177/1745691614551642)).
